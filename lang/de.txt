# Diese Übersetzung stammt von einer KI und wartet darauf, dass jemand sie
# liest, der die Sprache wirklich spricht. Wer etwas besser weiß: Zeile
# ändern, `python3 tools/make_lang.py` laufen lassen, fertig. Ohne Werkzeug
# geht es auch -- eine Datei /sd/synthminer/lang/de.txt auf der Karte mit
# denselben Zeilen sticht die eingebaute Fassung (i18n.h).
#
# Die Schlüssel stehen in lang/en.txt. Was dort an %-Platzhaltern steht, muss
# hier wieder vorkommen; verschieben darf man sie mit %2$s, weglassen nicht.
