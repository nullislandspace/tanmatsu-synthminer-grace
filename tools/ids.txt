# =====================================================================
#  SynthMiner  --  every block id and item name ever shipped (D-74)
# ---------------------------------------------------------------------
#  Worlds on people's cards store BLOCKS as one-byte ids and ITEMS by
#  name (inventories, dropped items, replays). So:
#
#    a block's id and name never change, and a block is never removed --
#    it is retired, keeping its line and its number;
#    an item's name never changes, and an item is never removed.
#
#  `make check` (worldcheck, "the id registry") fails the build if the
#  code disagrees with this file in any way: an id renumbered or renamed,
#  a line with no block or item behind it, or a block or item in the
#  code that is not listed here. Adding one is appending a line, in the
#  same commit -- deliberately, since after the first build that ships
#  it, that line is forever.
#
#  block <id> <name>
#  item <name>
# =====================================================================
